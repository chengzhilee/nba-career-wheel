# 大转盘 NBA 生涯模拟器

一个网页版文字经营游戏：通过 13 个转盘抽取一位球员的天赋与身体条件，从大学篮球一路打到 NBA，经历选秀、交易、伤病、荣耀与遗憾，直到退役生成一张专属生涯总结海报。

> 灵感源自短视频创作者「看看可」的《大转盘第一期》系列玩法。

## 玩法流程

1. **13 连抽转盘**：身高 / 体重 / 臂长 / 天赋 / 位置 / 速度 / 球员特质 / 巨星能力（48 位球星招牌动作）/ 进攻·传球·抢断盖帽档位 / 入盟年龄 / 生涯长度（支持一键连抽与跳过动画）
2. **身体设置**：捏脸（肤色/发型/发色）、随机姓名、BMI 体型评价（偏瘦对抗吃亏、壮硕牺牲机动性）
3. **怎样打球**：自由描述你的打法，关键词会真实影响属性生成
4. **你的起点**：16 项属性与固定上限，天赋决定加点费用，身体与打法决定上限
5. **NCAA 大学生涯**：选择大学，逐年历练，积累荣誉，决定何时宣布参选
6. **选秀夜**：乐透抽签 + 行情模拟，状元也有"不可错过新星"的门槛
7. **NBA 生涯**：
   - 42 名随年份演化的虚拟球星与你真实竞争 MVP / 得分王 / 最佳阵容
   - 完整季后赛对阵图：抢七、横扫、下克上都有专属叙事
   - 伤病事件化（含重伤复出叙事）、交易请求、自由市场报价（2~4 份）
   - 全明星周末（三分 / 扣篮大赛 / AMVP）、奥运之夏（每 4 年）
   - 状态曲线：新秀成长 → 巅峰期（25~29 岁）→ 末期衰退
   - 训练馆加点（按总评权重一键分配）、属性雷达图、生涯中可改造位置
8. **退役**：NBA CAREER SUMMARY 海报（生涯总薪资、传奇同龄对比、名人堂判定、球衣退役），可一键导出为图片

## 特性

- 🎲 13 种转盘，每个都有独立的配色与手感
- 📈 数值体系经多轮平衡：状元需要历史级履历，二轮秀逆袭成就等你解锁
- 🏆 14 个生涯成就（一人一城 / Win for the City / 他们说我只是个二轮秀……）
- 📖 生涯纪念册：首秀、里程碑、荣誉、成就全记录
- 🏛 本机荣誉室：历代退役球员可随时回看
- 💾 存档：自动存档 + 手动存档 + 导出 / 导入文件
- 🔊 WebAudio 音效（可静音）

## 运行

无任何依赖，直接双击 `index.html` 即可离线游玩；或部署到任意静态托管。

## 技术说明

- 单文件实现（HTML + CSS + JS，约 4000 行），无构建、无框架
- 转盘为 SVG 渲染 + requestAnimationFrame 缓动
- 存档使用 localStorage，密钥与隐私数据零上传
- 浏览器控制台暴露 `window.__game` 调试钩子（如 `__game.fullCareer()` 一键跑完整生涯）

## 已知限制

- 存档保存在浏览器本地，换设备 / 清缓存不会同步（可在标题页导出存档文件备份）
- 虚拟球星数据为模拟生成，数值经过平衡但非真实历史数据
